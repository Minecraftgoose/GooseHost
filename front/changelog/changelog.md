## 🚀 v1.2.0 - 2026年8月6日

### 新增
- **多文件网站（Beta）**：支持上传 zip 压缩包创建多文件网站（代码/文本文件），访问 `/p/<slug>/<路径>`
- **文件级管理**：多文件站点详情页支持在线编辑、删除、拖拽替换单个文件
- **站点访问量**：所有站点自动统计访问量，Dashboard 概览/我的网站/Admin 均可见
- **Admin 独立详情页**：后台站点列表瘦身，点名称进入完整详情页（文件管理、编辑、删除、拖拽替换）
- **Admin 公告推送**：后台发布全局公告，用户 Dashboard 顶部横幅展示
- **Admin 站点详情**：多文件站点文件树、存储占用预览、删除前展示文件清单
- **多文件站点 IP 记录**：修复多文件站点创建时未记录来源 IP 的问题
- **首页全站统计**：官网首页展示托管网站数与累计访问量
- **引导式创建向导**：部署页三步引导（填名称 → 选类型 → 传内容）

### 修复
- **相对路径解析**：用户站点 HTML 内相对路径（style.css 等）在带参数访问时解析错位导致 404，已注入 `<base>` 修复
- **/p/ 路由 HEAD 请求**：修复 HEAD 请求返回 404
- **文件列表路径**：修复 Admin 详情页多文件站点文件列表为空（存储桶前缀错误）
- **Monaco 加载**：编辑器 CDN 切换至 bootcdn，修复境内加载失败

### 优化
- **编辑窗口合体**：HTML/Markdown 输入框与拖拽区域合并，拖文件直接落入编辑器
- **Admin 补齐**：站点列表类型徽章、文件级编辑、删除占用展示
- **文档升级**：API 文档与用户协议/隐私政策更新（多文件网站、账号接口、限流档位、数据采集说明）

## 🚀 v1.1.9 - 2026年7月28日

### 新增
- **用户昵称**：注册可选填昵称，Dashboard 账户页显示并可修改
- **忘记密码**：登录页新增「忘记密码？」入口，输入邮箱即可接收重置链接
- **重置密码**：独立重置密码页面，从邮件链接跳转设置新密码
- **注销账号**：账户页新增「注销账号」功能，确认后永久删除账户及全部站点
- **欢迎语打字机**：开屏动画后全屏欢迎语逐字显示，昵称保留绿色高亮
- **欢迎动效开关**：偏好设置可关闭开屏欢迎动画

### 修复
- **login.html 语法错误**：修复 `<script>` 未闭合导致 `Unexpected token '<'`，找回密码弹窗无法打开
- **昵称显示空白**：修复 `/api/me` 字段名取错导致昵称恒显示「未设置」
- **跨域限制**：修复部分操作因跨域限制被浏览器拦截的问题
- **邮箱防刷**：优化邮箱维度防刷拦截策略
- **弹窗崩坏**：注销账号弹窗改用独立自定义对话框组件，修复定位/遮罩缺失

### 安全
- **防刷全面接线**：为关键操作补全防刷保护

### 优化
- **后端架构**：后端架构优化，增强稳定性与安全性
- **打字机效果**：Dashboard 5 个页面页头文案逐字显示
- **Admin 昵称**：右上角展示当前用户昵称
- **字体统一**：补全全站字体统一
- **账户页布局**：昵称与邮箱位置上下颠倒

## 🚀 v1.1.6 - 2026年7月14日

### 全新交互系统

#### ✨ 动效大换血
- **性能优先**：全站 `transition: all` 全部替换为属性级 transition，GPU 友好，不再无谓重排
- **告别上浮**：删除了所有卡片/按钮的 hover translateY 上浮，改为**无方向绿色辉光阴影**
- **图标微动效**：所有 Font Awesome 图标鼠标悬停时温和放大 + 颜色平滑过渡，加载旋转图标排除
- **删掉土味**：删了快捷卡老土的 `bounce` 弹跳动画

#### 🎬 页面入场各不同
每个页面都有了自己专属的入场动画，不重复、不花哨：
| 页面 | 动画 | 效果 |
|------|------|------|
| 🚀 部署 | `deployEnter` | 淡入上滑 |
| ⚙️ 偏好·👤 账户 | `pullIn` | 右侧拉入 + 弹簧回弹 |
| 📊 概览 | `popReveal` | 弹入放大 |
| 🌐 我的网站 | `fadeSlideLeft` | 左侧划入 |

#### 🔧 其他体验改进
- **浮动标签输入框**：登录/注册/子域名输入框改为 Material 风格浮动标签，聚焦时文字上浮到边框
- **类型选择器瘦身**：部署页 HTML/MD 选择器从傻大方卡改成了紧凑分段控件
- **类型切换动画**：切换 HTML/MD 时有平滑淡入上滑
- **布局修复**：偏好页 Monaco toggle 和清除数据按钮不再换行
