# GooseHost 用户使用手册

> 最后更新：2026-08-08
>
> 从零开始，用 GooseHost 托管你的第一个网站。

---

## 一、快速上手

1. **注册账号**：打开 [host.goose.gs.cn](https://host.goose.gs.cn) 点「开始探索」，或直接访问 `/register`。填写邮箱、密码、昵称后提交，到邮箱点击验证链接完成注册。
2. **登录**：访问 `/login`，输入邮箱密码。登录状态会自动保持（登录一次，长期有效，无需反复登录）。
3. **创建网站**：登录后进入 Dashboard，左侧「部署」→ 填网站名称 → 选类型 → 粘贴代码或上传文件 → 部署。
4. **访问网站**：部署完成后会得到形如 `page.goose.gs.cn/s/你的网站名` 的访问地址，发给任何人都能打开。

## 二、三种网站类型

| 类型 | 适用场景 | 创建方式 | 访问路径 | 限制 |
|------|----------|----------|----------|------|
| HTML 网站 | 单文件网页 | 粘贴 HTML 代码 | `/s/<名称>` | ≤ 500KB |
| Markdown 网站 | 文档/博客 | 粘贴 Markdown | `/md/<名称>` | ≤ 500KB |
| 多文件网站 | 完整前端项目 | 上传 zip 压缩包 | `/p/<名称>` | 见下方说明 |

### 多文件网站（zip 上传）

- 压缩包内只支持**代码/文本类文件**：`html css js md json svg xml yml toml txt ts py c java go sh vue svelte wasm` 等
- 需包含 `index.html` 或 `index.md` 作为入口
- 单文件 ≤ 200KB，总大小 ≤ 2MB，最多 50 个文件
- 图片、视频、音频等二进制文件**不支持**（会被拦截），请改用外部图床
- 支持子目录：如 `assets/js/main.js`

### 编辑窗口使用

HTML / Markdown 编辑窗口已合体：**直接把文件拖进输入框**即可自动读取内容，也可以点击输入框下方的「点击选择」上传文件，或者直接粘贴代码。

## 三、管理你的网站

### 我的网站列表

Dashboard → 「我的网站」：

- 每个网站显示类型标签、**访问量**、创建/更新时间
- 点击网站进入**详情页**

### 网站详情页

- 顶部：访问（新窗口打开）、编辑、删除
- 信息区：类型、访问量、创建时间、更新时间
- **文件列表**（多文件网站）：
  - 每行可「编辑」（弹窗修改内容）或「删除」
  - **拖拽文件到某一行可直接替换**该文件
  - 单文件 ≤ 200KB
- 编辑 HTML/MD 网站：弹窗编辑，支持 Monaco 编辑器（偏好设置里可开关）

### 访问量统计

每个网站自动统计访问次数（页面打开即 +1），无需任何配置。Dashboard 概览页显示你的**总访问量**，官网首页显示**全站统计**。

## 四、账号与安全

### 昵称

- 注册时必填，2-20 个字符（中文、字母、数字、`_` `-` 空格）
- 登录后可在 Dashboard → 账户设置修改

### 忘记密码

登录页点「忘记密码？」→ 输入邮箱 → 收到重置邮件 → 点链接设置新密码。
防刷：每 IP 每小时 5 次，每邮箱每小时 3 次。

### 注销账号

Dashboard → 账户设置 → 注销账号。确认后**永久删除账号及全部网站**，不可恢复，请谨慎操作。

## 六、常见问题（FAQ）

**Q：为什么我上传的图片显示不出来？**
多文件网站白名单只接受代码/文本文件，图片等二进制资源会被拦截。请把图片传到外部图床，在 HTML 里用完整 URL 引用。

**Q：网站能绑定自己的域名吗？**
目前不支持自定义域名，使用平台分配的 `page.goose.gs.cn/...` 地址。

**Q：网站被删了能恢复吗？**
不能。删除操作不可逆，请提前备份源码。

**Q：访问量是怎么计算的？**
每次有人打开你的网站页面（HTML/MD 入口或多文件网站的 index）计数 +1，静态资源（css/js/图片）不计。刷新页面会计数。

**Q：免费吗？**
免费。平台保留未来调整服务模式的权利，调整会提前公示。

**Q：有使用限制吗？**
为防滥用，创建网站有限流（每 IP 每分钟 2 次），单用户站点数量暂无上限。
